买断版还有团队阶梯价。单人 87 美元，一次买 2 个及以上走团队价，每个 80 美元，人越多单价越低，到 1000 用户规模时每个降到 20 美元。团队采购别一个个下单，走团队授权能省一截。

## 多花的钱换到了什么：把六个版本算成月均价

先看买断和订阅的临界点。Standard 年付每月 7 美元，买断 87 美元，87 ÷ 7 ≈ 12.4。也就是说同样一笔钱，买断能用满 13 个月才开始比订阅划算。但买断的授权是永久的，只是免费更新只管购买日起一年内发布的版本，一年后想升到新版本要另外付费；订阅一旦停付，软件就不能继续用。所以这不是纯粹的算术题：打算用两年以上、且不介意停在某个版本，买断明显更省；打算长期跟进新功能，或者需要跨设备，订阅更顺。

再看 Ultimate 比 Standard 多出来的 2 美元/月，一年 24 美元，买到的是 2 台额外设备和云端截图。设备数从 3 台到 5 台，对只有一台台式机加一台笔记本的人是浪费；对同时用公司电脑、家里台式、平板和手机的人来说，3 台很容易不够。截图功能的意义在于留证据，比如给客户报工时、给外包结算，没有这类需求就不用加钱。

团队版比个人版贵 3 美元/用户/月，一年多 36 美元/人，多的是服务端报表和集中管理。两三个人的小团队其实可以看买断的团队授权：2 人起每个 80 美元，两个人 160 美元一次性，而同规模用 Cloud 团队 Standard 一年就要 240 美元。代价是没有官方云同步，得自己装 Server 或者各自本地记录。

## 常见问题

**免费版能长期用吗？**
能，没有时间限制。限制在功能上，自动标签、工时表、高级搜索这些都要付费版。

**买断版以后升级要另外花钱吗？**
购买日起一年内发布的版本免费升，一年后的新版本需要付费。

**学生有折扣吗？**
有。27 岁及以下在校学生和退休人士可以发邮件到 support@manictime.com 申请，需要身份证明，授权仅限非商业用途。

**换电脑了授权还能用吗？**
取决于版本允许的最大激活设备数，这个数字写在商品页的规格说明里，下单前先确认。

**团队最少几个人买？**
Cloud 团队版按用户数买，人数没硬性下限；买断的团队授权 2 用户起。
